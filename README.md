# Week 2 EDA Submission

## Files
- `Week2_EDA_Final_Report.docx`: report with findings, visualizations, interpretations, limitations, and references.
- `week2_eda_analysis.py`: complete reproducible analysis code.
- `requirements.txt`: required Python packages.
- `figures/`: figures included in the report.

## Run locally
```bash
python -m pip install -r requirements.txt
python week2_eda_analysis.py
```
Outputs are written to `week2_eda_outputs/`.

## Dataset
The Wine Recognition dataset is distributed with scikit-learn and originates from the UCI Machine Learning Repository. The code loads it with `sklearn.datasets.load_wine`, so no separate CSV download is needed.

## Before submitting
1. Open the DOCX and fill in your name and submission date.
2. Run the script on your own computer or in Google Colab.
3. Check that output figures and `eda_summary.txt` are generated.
4. If the portal requires evidence screenshots, capture your own run.
5. Submit the DOCX as requested and attach the Python file if the portal allows.
